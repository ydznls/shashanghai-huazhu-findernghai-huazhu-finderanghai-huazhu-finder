# 上海华住酒店筛选

按品牌、地铁站距离、开业时间、点评分数和入住日期筛选上海华住酒店，并在程序内查看官网参考价及房型。

## 已实现

- 品牌目录涵盖 39 个品牌或系列、10 个类别；上海酒店资料包含 901 家酒店。
- 官网参考价、房型信息、价格采集时间及官网预订入口。
- 黄金会员 88 折、铂金会员 85 折的计算估算，明确区别于实际会员报价。
- 对筛选结果批量查价，支持进度、暂停、继续及失败重试；切换日期后自动查询前 30 家。
- 浏览器按入住日期保存价格缓存，最长 48 小时。查询失败不会伪装成零元或售罄。

## 本地运行

需要 Node.js 22.13 或更新版本，建议 Node.js 24。

```sh
npm ci
npm run dev
```

打开终端显示的网址，通常是 http://127.0.0.1:5173/。

```sh
npm run check
npx tsc --noEmit
npm run build
npm start
```

`npm start` 运行构建后的本地 Worker 预览，网址以终端输出为准。技术栈为 React、TypeScript、Vinext、Vite 和 Cloudflare Workers。

## 价格与数据口径

随仓库提供的报价快照对应 **2026-10-23 入住、2026-10-24 离店**：901 家酒店中，842 家获得参考价，55 家没有可用参考价，4 家遭遇请求限流。历史快照不代表当前库存或当前成交价。

主价格采用华住官网返回的划线参考价 `marketPrice`；黄金、铂金金额分别由参考价乘以 0.88、0.85 得到，仅供估算。实际会员折扣、房型、早餐、取消规则和最终金额以官方预订页面为准。查询默认一间房、一位住客。

切换日期后会重新查询；不同日期的价格不会互相套用。官方接口可能限流、返回空数据或改变结构，因此不能保证每家酒店实时有价。批量查询期间需要保持页面打开。

截至 2026-10-23，已核对 897 / 901 家酒店的官方开业日期；剩余 4 家官方字段为空。开业日期优先读取官方列表及详情接口的 businessDate，按酒店编号匹配并保留来源与核对时间。另有 164 家具备明确地铁距离、505 家有有效点评分数；缺失字段会保留缺失状态，不以推测值补齐。实时接口可补充部分数据。精确的房型条件筛选尚待实现。

可选的离线更新命令：

```sh
node scripts/collect-official-prices.mjs 2026-10-23 2026-10-24
```

省略日期时使用上海时区的次日入住、再下一日离店。该命令会请求官方服务并更新数据文件，请避免重复密集运行。

开业日期可以批量补采，先读取官方列表，再逐店核对少数缺项；支持中断后继续：

```sh
node scripts/collect-opening-list.mjs
```

`data/official-opening.json` 保存逐店核对记录。筛选“2023 年及以后开业”目前有 346 家；再加“地铁 1 公里内、评分 4.7+”时有 2 家符合已核实条件，未知字段默认不算满足条件。

## 分享与部署

GitHub 仓库用于公开源码。当前程序包含酒店资料和实时查价的服务端接口，GitHub Pages 的静态托管不能直接运行这些接口。完整在线版本需要兼容 Vinext / Cloudflare Workers 的运行环境，并自行配置部署。

仓库中的 `.openai/hosting.json` 仅保留空资源配置，不包含原站点标识、发布凭据或个人机器路径。

## 目录

- `app/`：页面与服务端接口。
- `components/`：酒店卡片、房型价格及批量查价界面。
- `lib/`：数据处理、报价验证、队列和缓存。
- `data/`：酒店资料、品牌目录和带日期的价格快照。
- `scripts/`：数据采集、验证和启动脚本。
- `build/`、`vendor/`：运行框架与上游代码。
